/ selected work

Engagements that
moved the needle.

A small selection of recent infrastructure and security work — measured by what changed, not what was deployed.

Identity

Cloud identity consolidation

Migrating enterprise applications and users from on-prem ADFS to Entra ID — a board-wide identity overhaul.

Challenge
Legacy ADFS infrastructure was fragile, hard to extend, and blocking modern conditional-access policies across 72 sites.
Solution
Phased migration of SaaS and internal apps to Entra ID, retiring ADFS while preserving SSO continuity and zero downtime for users.
Technologies
Entra IDADFSSAMLOIDCConditional Access
Outcome
Single source of identity truth, modern conditional-access enforced org-wide, and the legacy ADFS farm fully decommissioned.
Security

Endpoint hardening program

A full Defender-led hardening rollout including ASR rules, web-content filtering, and certificate-trust renewal.

Challenge
Endpoint posture was inconsistent, ASR was unconfigured, and the root CA was approaching expiry across all workstations and servers.
Solution
Deployed Defender ATP with tuned ASR rules and web-content indicators; renewed the Root CA and redistributed certificates fleet-wide.
Technologies
Defender ATPASRPKINetskopeZscaler
Outcome
Measurable reduction in attack surface, zero certificate-trust incidents at cutover, and an auditable security baseline.
Cloud Platform

Azure Virtual Desktop platform

A cost-optimized AVD environment serving high-end computing needs for distributed users.

Challenge
High-spec workstations were over-provisioned and idle most of the day — a poor fit for distributed, sporadic workloads.
Solution
Designed an AVD environment with Nerdio automation, FSLogix profiles, and Teradici integration for graphics-intensive use cases.
Technologies
AVDNerdioFSLogixTeradiciAzure
Outcome
Compute consumed only when used; on-demand scaling replaced fixed hardware costs and freed capital for higher-value work.
Automation

Autopilot & provisioning automation

PowerShell tooling that took technician device onboarding from manual to one-click.

Challenge
Onboarding new devices into Autopilot required multiple manual steps and CSV uploads — slow, error-prone, and inconsistent.
Solution
Built a custom PowerShell deployment that captures hardware hashes and uploads them into Windows Autopilot automatically.
Technologies
PowerShellGraph APIAutopilotIntune
Outcome
Device provisioning time cut dramatically; technicians enroll fleets without touching the Intune console.
